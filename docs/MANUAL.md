# Paper Library Guide

Open the website at `http://localhost:8000/llm-wiki-source/` after starting a server from the Papers folder as described in `README.md`.

- **Paper map:** drag to pan and scroll to zoom. Select a point to view its abstract and open the original PDF.
- **Catalog:** search by title, topic, DOI, filename, or abstract; sort by year or title.
- **Topics:** select a tag to filter papers on the map or in the catalog.

The website was generated from 120 PDFs in the Papers folder. Titles, years, DOIs, page counts, and abstracts are extracted automatically when possible; scanned PDFs may not contain extractable text. DOI links found in a file and topic-based links are suggestions. Open the original paper to verify citation details.

When you add PDFs, rerun the commands in the “Update the catalog” section of `README.md`. The original PDF files remain in the Papers folder.
