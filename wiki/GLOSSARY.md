# GLOSSARY — Fixed Korean→English Terminology Table

Single source of truth for translating this wiki's Korean notes into English.
Every translation task must apply these renderings exactly. Do not invent variants.

Conventions baked into this table:
- One space between value and unit; the degree sign attaches only to angles
  (`90°`, but `20 °C`).
- Symbol subscripts stay as in the source: σcc, σpc, εpc, J′_b, J_tip.
- Abbreviations (ECC, SHCC, PVA, PE, W/B, SP) pass through unchanged.
